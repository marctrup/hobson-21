The four pricing models to recognise

Per-unit pricing grows with the number of properties or units managed. Check minimum charges and what the supplier counts as a unit, particularly for shared premises or mixed-use buildings.

Per-seat pricing grows with the number of people using the system. Check whether occasional reviewers, external advisers and administrators need paid seats.

Tiered subscriptions bundle capacity and functionality. A low starting price may exclude reporting, integrations or support that your team needs.

Quote-based pricing is common where configuration and portfolio complexity matter. Ask for a written breakdown so implementation and recurring charges can be compared separately.

Build a first-year budget

Use this calculation: first-year cost = setup and migration + document preparation or learning + subscription payments + required extras. Include VAT where applicable and allow for internal staff time.

Ask whether the advertised price assumes annual payment, whether renewal pricing changes and what happens if your portfolio grows. A monthly equivalent on an annual contract is not the same as a cancellable monthly subscription.

  • User training and implementation support.
  • Required integrations, storage and usage allowances.
  • Additional people, properties or newly added documents.
  • Export, cancellation and renewal terms.

How Hobson prices the work

Hobson’s current public pricing separates one-off document learning from ongoing seats. The page shows £35 per person per month, with the complete product rather than feature-gated seat tiers.

The document calculator shows an estimated reading range of £0.25–£0.40 per document. This is an estimate, not a fixed quotation: the reading fee needs approval before work begins. Human Concierge document preparation is shown separately at £2.50 per document, with a ten-document minimum; do not confuse that service with the automated reading estimate.

For illustration, four standard seats are £140 per month. Reading 1,000 documents at the displayed estimate would be £250–£400 once. Twelve paid seat months plus that reading estimate would total £1,930–£2,080 before any applicable tax, optional services or offers.

The Pricing page also describes the Together offer, under which the first month of seats is waived once the reading fee is approved. The example above deliberately excludes offers. Use the live calculator and confirm tax treatment, service scope and terms in your quote.

Compare quotes on the same basis

Arthur publishes unit-based plans, Landlord Vision publishes portfolio-based plans, and Re-Leased provides tailored pricing. Their scope differs, so dividing each quote by the number of properties is not enough to establish value.

Give suppliers the same brief: portfolio size, number of users, document volume, required workflows, accounting tools and implementation date. Ask each to identify both what is included and what would need another system.

Vendor prices can change. The official pricing pages below are the place to check current amounts and terms; this guide does not reproduce temporary discounts or claim a market-wide price range.

Measure value against a real task

Choose a repeatable task such as checking a rent review clause across a set of leases. Record the time spent finding documents, verifying answers and preparing the result. Then repeat the task during a supervised trial.

Any saving should be measured rather than assumed. A cheaper subscription is not better value if it leaves the important work manual; a more expensive one is not justified by features your team will never use.

Frequently asked questions

How much does property management software cost in the UK?+

There is no single UK price. The cost depends on the number of properties or people, the work included and the effort needed to set up your records. Compare the first-year total — setup, migration, subscription and required extras — not just the headline monthly subscription.

What pricing models do suppliers use?+

The four common models are per-unit pricing, per-seat pricing, tiered subscriptions and quote-based pricing. Each grows differently as your portfolio or team changes, so ask how minimum charges and renewals work in each case.

How much does Hobson cost?+

Hobson’s public pricing is £35 per person per month for the complete product, plus a one-off document reading estimate of £0.25–£0.40 per document. Human Concierge document preparation is a separate optional service. Use the live calculator on the Pricing page for current figures.

How should I compare quotes from different suppliers?+

Give each supplier the same brief: portfolio size, number of users, document volume, required workflows and implementation date. Ask each to identify what is included and what would need another system, then compare full first-year costs and renewal terms.

Is the cheapest software the best value?+

Not necessarily. A cheaper subscription is not better value if it leaves the important work manual, and a more expensive one is not justified by features your team will never use. Measure value against a real, repeatable task before deciding.
